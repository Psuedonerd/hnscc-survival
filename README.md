This project develops and validates a predictive model for HPV-Negative Head and Neck Squamous Cell Carcinoma based on clinicogenomic data. In this repository, all code needed for local reproduction of the methodology is contained.

All data was sourced from The Cancer Genome Atlas (TCGA) and the Clinical Proteomic Tumor Analysis Consortium (CPTAC). Feel free to visit these open repositories of data to download for yourself and expand on this approach. 

The complete paper can be found under "HNSCC_Survival_Paper.pdf," and outlines an analysis taken with the approach present.
